### 一、 上周核心学习成果

1. **深度网络前向计算与激活函数体系**：
   - 掌握神经网络拓扑架构与前向映射公式 $y = f(\mathbf{w}^T\mathbf{x} + b)$，深入理解万能近似定理及激活函数打破线性叠加的本质。
   - 对比掌握 Sigmoid、Tanh、ReLU 及 Softmax 的数学公式、输出区间与导数特性；剖析饱和区梯度消失成因，明确隐藏层首选 ReLU 与输出层（Sigmoid 二分类 / Softmax 多分类）的任务选型。
   - 理解参数初始化（He / Xavier 原理与实现）在打破对称性与稳定数值方差上的关键作用。

2. **损失函数与梯度下降优化方法**：
   - 梳理多任务损失体系：掌握二分类/多分类交叉熵损失推导，对比 MAE、MSE 与 Smooth L1 回归损失的鲁棒性。
   - 深入理解反向传播（BP）算法与链式法则求导逻辑，回顾基础梯度下降算法；重点掌握 Adam 优化器结合一阶动量与二阶矩估计（RMSProp 自适应平滑）的动态调整机制。

3. **学习率调度与深度学习正则化**：
   - **学习率衰减**：掌握等间隔（StepLR）、指定间隔与指数间隔衰减策略，平衡前期跳出鞍点与后期平稳收敛。
   - **正则化与防过拟合**：掌握权重惩罚（L1/L2）、Dropout（随机失活的训练置零与测试缩放）以及批量归一化（BatchNorm 缓解内部协变量偏移）的原理与代码实现。

4. **端到端综合实战：手机价格分类预测**：
   - 剖析多维连续与离散特征，规范完成特征工程与防数据泄漏的数据集划分。
   - 基于 PyTorch 搭建多层感知机（MLP），组装 `Linear -> BatchNorm1d -> ReLU -> Dropout` 结构与交叉熵损失，规范编写训练、验证、测试与调优全链路代码，闭环分类评估。
